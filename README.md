# Выбор времени запуска вычислительных задач

Проверяем, можно ли применять во Франции модель прогноза углеродоёмкости электроэнергии, обученную в Великобритании. Система рекомендует время запуска в пределах допустимой задержки. Если прогнозируемая экономия относительно запуска сразу превышает заданный порог, система рекомендует перенос.

На одних и тех же французских данных сравним два порога: рассчитанный по британским данным и пересчитанный по короткому периоду французских данных. Модель не дообучаем. На отдельном тестовом периоде измерим экономию расчётных выбросов, частоту переносов и долю задач, для которых перенос увеличил выбросы.
